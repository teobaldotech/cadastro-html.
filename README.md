# Formulário de Cadastro de Usuários — HTML5

Projeto de formulário de cadastro de usuários desenvolvido com HTML5, CSS3 e JavaScript puro, com interface responsiva e validação de dados no navegador.

## Funcionalidades

- Cadastro de nome completo e e-mail.
- Campo de telefone.
- Data de nascimento com restrição para datas futuras.
- Seleção de gênero.
- Campos de endereço, cidade, estado e CEP.
- Senha e confirmação de senha.
- Validação de campos obrigatórios.
- Formatação automática do CEP.
- Botões para cadastrar e limpar o formulário.
- Layout responsivo para computadores, tablets e celulares.
- Mensagens de sucesso e validação acessíveis.

## Tecnologias utilizadas

- **HTML5:** estrutura semântica e campos do formulário.
- **CSS3:** estilização, layout responsivo e efeitos visuais.
- **JavaScript:** validação de dados e interatividade.

## Estrutura do projeto

```text
formulario-cadastro-usuarios/
└── index.html
```

## Como executar

1. Baixe ou clone o projeto.
2. Localize o arquivo `index.html`.
3. Abra o arquivo diretamente no navegador.
4. Preencha os campos e clique em **Cadastrar usuário**.

Não é necessário instalar dependências ou executar um servidor para testar esta versão.

## Validação

O formulário utiliza recursos nativos do HTML5 e validações em JavaScript para verificar:

- Campos obrigatórios.
- Formato do e-mail.
- Comprimento mínimo da senha.
- Correspondência entre as senhas.
- Data de nascimento.
- Formato da sigla do estado.
